# Start here

**Easiest path (recommended, no coding required):** open `CLAUDE_SETUP.md` in
this repo, copy the whole file, and paste it into a new Claude conversation
(claude.ai, or Claude Code if you have it). Claude will ask you a handful of
questions about your newsletter and then does the setup with you: writing
`PLAYBOOK.md`, `LEARNINGS.md` and `config/brand.json`, walking you through the
four accounts you need (Anthropic, Beehiiv, Gmail, optionally Notion and
Giphy), and wiring the GitHub Actions secrets.

**If you'd rather read the full explanation first:** read `PROTOCOL.md` top to
bottom. It's written for a non-developer operator -- twelve minutes, no jargon
left unexplained. It covers what this system is, why every piece is chosen,
the exact install steps, and how to adapt the voice and structure to your own
newsletter.

**If you already know what you're doing (engineer skimming a template):**
`README.md` has the architecture map and file list.
